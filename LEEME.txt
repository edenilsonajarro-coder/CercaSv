CercaSV — proyecto web
=====================

Archivos principales:
- index.html: estructura de la página
- style.css: estilos
- app.js: interacciones y conexión con Supabase
- .github/workflows/pages.yml: publicación automática en GitHub Pages

Desarrollo local:
1. Abre la carpeta del proyecto en Acode o un editor.
2. Abre index.html con Preview o un servidor local.

Publicación:
- El workflow de GitHub Actions publica el contenido de la raíz.
- En GitHub, entra a Settings > Pages y selecciona GitHub Actions como fuente.
- Después de habilitar Pages, los cambios enviados a main pueden publicarse automáticamente.

La aplicación usa Supabase para autenticación y datos. GitHub Pages solo aloja los archivos estáticos; no ejecuta backend propio.
